
## Data

1. Go to the UCSC Table Browser: https://genome.ucsc.edu/cgi-bin/hgTables
2. Set the fields to the following:
- Clade: Mammal
- Genome: Human
- Assembly: Feb. 2009 (GRCh37/hg19)
- Group: Genes and Gene Prediction Tracks
- Track: NCBI RefSeq
- Table: ncbiRefSeq (or ncbiRefSeqCurated if you want only curated RefSeq entries)
3. Get the output by clicking "Get output"
4. Copy the data to your "{genome_version}_refseq.ucsc" file in your data directory
